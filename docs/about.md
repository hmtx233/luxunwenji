# 关于本站

## 为什么做这个站

鲁迅的作品，论篇目之全，早已有《鲁迅全集》在；论考据之精，也早有各种校注本。这样一个站点，看起来似乎是多余的。

但读鲁迅有一个具体的困难：**他的文字散落在不同的集子里，而集子的编排逻辑并不总是清楚的。**

《呐喊》里为什么是《狂人日记》开篇？《野草》里那几篇只有几百字的散文诗，彼此之间是什么关系？《且介亭杂文》的"且介"二字是什么意思？这些问题的答案，往往藏在原书的序跋、题记、后记之中——而那部分内容，在大多数网络流传的版本里恰恰是被省略掉的。

于是就有了这个站：**把每部文集按它原本的样子呈现出来——包括序跋，包括篇序，包括文末的写作日期。**

不节选，不改编，不加入任何解释性的导读。只做一件事：把原文放在一个安静的、适合长时间阅读的页面上。

## 编排原则

**篇序从原著。** 每一部文集内部的篇目顺序，依照初版或通行的《鲁迅全集》编排，不按拼音、不按篇幅、不按年代重排。例如《呐喊》以《自序》起、以《社戏》终；《中国小说史略》严格依"第一篇"至"第二十八篇"的次序。

**序跋不删。** 题记、序言、小引、后记一律保留，并置于所属文集的起始位置。它们既是文献，也常常是理解正文的钥匙。

**文末日期保留。** 鲁迅多数文章末尾有写作落款（如"一九二〇年十月。"），本站将其另起一行、右对齐呈现，位置和原书一致。

**分体处理。** 对话与韵文按其本身的分行呈现，不强行合并为整段；章节序号居中单列。

## 关于文本

本站正文主要依据鲁迅著作的公有领域文本整理。鲁迅先生于 1936 年逝世，其作品在中国已进入公有领域。

需要说明的是：**数字化过程中难免引入讹误。** 异体字、通假字、旧式标点、民国时期的用词习惯都尽量存其原貌，未作现代化改写。偶有错漏，欢迎指出（见文末）。

本站**不提供**任何注释、译文或评析，以免以己意代作者之意。若需考据与注解，请以人民文学出版社《鲁迅全集》等权威版本为准。

## 关于错误

如果发现以下问题，欢迎反馈：

- **文字讹误**：错字、漏字、串行、标点异常
- **篇目问题**：顺序有误、文集归属不对、缺篇或重篇
- **链接失效**：站内跳转出错、检索结果打不开
- **页面异常**：在特定设备或浏览器上显示错乱

反馈时若能注明**文集名 + 篇名 + 具体位置（原句）**，处理起来会快很多。
